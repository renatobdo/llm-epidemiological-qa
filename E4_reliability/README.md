# E4_reliability

## Evidence Documents

The `data_docs/` directory contains the evidence documents used in the experimental evaluation of the question-answering systems.

These documents are maintained in a shared directory to facilitate reproducibility and comparison across the four deliverables (E1–E4).

Each experiment may use a different subset of these documents, depending on its objectives and architecture.

The repository documentation identifies the evidence sources, experimental configurations, and document selection criteria whenever applicable.
